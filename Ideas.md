# Ideas

## General

- All files, regardless of wether or not they were scanned by AI, should just allow to expand the source code. (see 1.png)
- When "Source" is expanded, it should have a toggle "Highlight" than can be turned on and off and uses syntax highlighting for the code based on programming language / filetype. 

- Tab System (see 2.png) -> instead of resetting the opened functions every time, one can keep the opened tiles open in a tab and open a new tab, that allows for a better overview.



## Search

- instead of just showing the file-names of a search beneath the search bar, they should be displayed in place of the first tile. 

- AI -> Next to the search bar should be an "AI" button that can be turned on and off. when on, the search bar instead becomes a context window in which someone can write something like "the function that triggers the backup" or "where the secrets are stored", and then the AI uses the information to quickly find the files and functions in question, and the search result will reflect those. 

## Connections

- Clicking inside the source-code (with or without highlight) on a certain function should also open the connection.
